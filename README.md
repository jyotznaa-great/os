
# Round Robin Scheduling Algorithm

## Aim
To implement the Round Robin CPU Scheduling Algorithm in Python.

## Description
Round Robin is a CPU scheduling algorithm in which each process gets a fixed amount of CPU time called a time quantum.

If a process is not completed within the time quantum, it is placed at the end of the ready queue.

## Features
- Accepts process details.
- Uses a fixed time quantum.
- Calculates waiting time and turnaround time.
- Displays the execution order of processes.

## Requirements
- Python 3.x

## How to Run
1. Open the project in Visual Studio Code.
2. Open the terminal.
3. Run the program:

   ```bash
   python round_robin.py
   ```

## Output
The program displays the process execution order, waiting time, and turnaround time.

## Conclusion
The Round Robin algorithm provides fair CPU allocation to processes using time-sharing.
